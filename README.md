# Orivelle

The Orivelle website is a small, fast Astro site introducing the brand and its desktop software for Windows and Linux.

## Getting started

```sh
npm install
npm run dev
```

Create a production build with `npm run build`, then preview it with `npm run preview`.

## Stack

- Astro and TypeScript
- Tailwind CSS 4 through its Vite plugin
- Anime.js 4 for restrained, progressive enhancement

The first release is a static landing page. Product names, descriptions, and download links should be added when those releases are ready.
